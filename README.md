# v8fmt
Formatter for 1C:Enterprise (1C v8) code inspired by PEP 8 — a style guide for writing clean and consistent BSL code. Includes CLI, auto-fix, and editor integration.

**v8fmt** — кроссплатформенная утилита командной строки для автоматического форматирования кода на BSL (1С:Предприятие 8).  
Поддерживает автоисправление стиля, единые правила оформления, конфигурационные файлы и интеграцию с редакторами.
